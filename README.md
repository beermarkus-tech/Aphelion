# Aphelion

An idle game about growing a handful of survivors on a dying world into a civilization that rewrites physics.
This is the MVP: **Era I — Cinder**, playable on phones, tablets and desktop browsers.

```bash
npm install
npm run dev        # open the printed Network URL on your phone or tablet
npm test           # sim + balance tests
npm run sim        # pacing report
npm run build      # static build in dist/ (host anywhere; installable as a PWA)
```

On a phone or tablet, open the site and use **Add to Home Screen** to install it as an app that runs offline.
See `CLAUDE.md` for architecture and `PROGRESS.md` for status.
